## 2026-06-24 - Levenshtein Distance Optimization in `pkg/stringutil`
**Learning:** In the `pkg/stringutil` package, `LevenshteinDistance` and `FindClosestMatches` are used for "Did you mean?" suggestions and typo corrections, which can be computationally active. Swapping the inputs so that the shorter string drives the DP array size allows us to use a stack-allocated buffer (`[65]int`) for common inputs of length up to 64 bytes. This completely eliminates heap allocations. Furthermore, in `FindClosestMatches`, a simple length-difference check can avoid calculating the distance completely if the length difference exceeds the maximum allowed edit distance (3), yielding a huge speedup.
**Action:** Always swap comparison arguments to minimize the inner-loop slice size, utilize stack buffers for small inputs to avoid heap allocation, and employ length short-circuiting where edit distance limits are known.
