## 2026-08-10 - Git Command Flag and Argument Injection
**Vulnerability:** Positional arguments such as Git refs, branch names, and file/directory paths are passed to Git subprocess commands (like `git clone`, `git ls-remote`, `git checkout`). If they are not validated, an attacker can supply hyphen-prefixed values (e.g., `--upload-pack=...` or `-f`) which the Git CLI interprets as command-line flags. This can lead to remote code execution (RCE) or argument injection.
**Learning:** Even when command arguments are passed as a slice of separate strings to `exec.Command` (preventing standard shell injection), flag/argument injection remains a critical risk. If user inputs are interpreted as flags by the underlying subprocess, security controls can be bypassed.
**Prevention:** Explicitly validate all user-controlled positional arguments passed to Git command executions (including refs, paths, and slugs) using a robust helper like `ValidateGitArg` to reject hyphen-prefixed inputs.
