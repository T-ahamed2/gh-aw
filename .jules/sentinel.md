## 2026-07-30 - Git Command Flag and Option Injection Mitigation
**Vulnerability:** User-controlled git arguments (such as branch/ref names, paths, or directory prefixes) passed directly to `exec.Command("git", ...)` can be used to perform flag or option injection if they start with a hyphen (`-`). For example, an input like `--upload-pack` could lead to command execution or information disclosure.
**Learning:** This existed because fallback command executions for git-based directory listing, file retrieval, and checking out specific versions/refs lacked validation for hyphen prefixes and did not utilize the `--` separator to signify the end of options in git commands.
**Prevention:** Always validate all user-controlled refs, branch names, and file paths with `ValidateGitArg` to reject leading hyphens before passing them to git commands, and always use the `--` option/positional delimiter in commands like `git ls-tree` to safely delineate command flags from positional paths.
